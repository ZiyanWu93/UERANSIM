### 🧭 Context: When is `Registration Accept` generated?

After successful authentication and security setup, the **AMF** sends the **Registration Accept** message to the **UE**, conveying registration success and assigning identifiers like GUTI, allowed NSSAI, timers, etc.

---

| Step | Field          | Value                            | Generated By | Description                                                                                           |
| ---- | -------------- | -------------------------------- | ------------ | ----------------------------------------------------------------------------------------------------- |
| 1    | `outer_header` | `"7e02"`                         | **AMF**      | Security-protected NAS header: EPD = 0x7e, header type = 0x02 (integrity + ciphered with new context) |
| 2    | `mac`          | `"7239674c"`                     | **AMF**      | 32-bit message authentication code (calculated over ciphered payload with `KNASint`)                  |
| 3    | `seq_num`      | `"01"`                           | **AMF**      | Sequence number to avoid replay (NAS-level counter)                                                   |
| 4    | `inner_header` | `"7e00"`                         | **AMF**      | Plain NAS message: EPD = 0x7e, header type = 0x00                                                     |

| 6    | `reg_result`   | `"0101"`                         | **AMF**      | IEI = 0x01, Registration Result = 0x01 (e.g., 3GPP access success)                                    |
| 7    | `guti_ie`      | `"77000bf299f907020040c0000727"` | **AMF**      | IEI = 0x77, 5G-GUTI assigned to UE. Contains MCC, MNC, AMF ID, TMSI                                   |

### 📜 Step-by-Step NAS Flow

```
[1] UE completes Security Mode Complete.
[2] AMF assigns 5G-GUTI and determines allowed NSSAI and TAI list.
[3] AMF assembles plain NAS message (Registration Accept).
[4] AMF applies ciphering + integrity protection (using KNASenc + KNASint).
[5] AMF builds outer NAS header, MAC, and sequence number.
[6] AMF sends Registration Accept to UE via gNB (N2).
```

---

### 🧠 Extra Notes

* **MAC** is computed using the selected integrity algorithm (e.g., 128-NIA2).
* **GUTI** format:

  * MCC + MNC
  * AMF Region ID + Set ID + Pointer
  * 32-bit TMSI
* **TAI list** lets the UE know where it can roam without needing re-registration.
* **NSSAI** (SST=1) corresponds to default data service (internet).
* **GPRS Timer** T3512 is used for periodic registration updates (a power-saving mechanism).
