### 📘 Context: When is this message sent?

The **AMF** sends a **Configuration Update Command** to inform the **UE** about changes in network-related configuration, like the **PLMN name**, **time zone**, **daylight saving time**, or **network time** after registration or handover.

---

### 🧠 Summary: Step-by-Step NAS Flow

```
[1] UE completes Registration Accept or Handover
[2] AMF detects updated configuration (e.g., PLMN name, time zone)
[3] AMF prepares inner NAS payload with full/short names and time IEs
[4] AMF wraps it with outer header, computes MAC and sequence number
[5] AMF sends Configuration Update Command via gNB (N2)
```

---

### 💡 Additional Details

* **PLMN names (IEI 0x43, 0x45)**: Transmitted in **GSM 7-bit or UCS2 (UTF-16)** encoding.
* **Time zone (IEI 0x46)**: Encoded as **signed 2's complement** in 15-min increments (`0x0A` = −10 × 15min = −150min = −2.5h → GMT-5 approximated).
* **UTC and Local Time (IEI 0x47)**: Contains full date/time in BCD format + time zone offset.
* **DST (IEI 0x49)**: `0x01` = +1 hour.
