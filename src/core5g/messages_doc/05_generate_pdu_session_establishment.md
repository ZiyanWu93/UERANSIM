### 🧠 Process Flow Summary

```
[1] UE sends PDU Session Establishment Request → AMF
[2] AMF routes to SMF (via Nsmf_PDU_Session_Create)
[3] SMF allocates:
     - IP address (10.45.0.2)
     - QoS flows and rules
     - NSSAI and AMBR
     - DNS info (via EPCO)
[4] SMF builds N1 SM message (Establishment Accept)
[5] SMF returns N1 SM to AMF → AMF encapsulates in DL NAS Transport
[6] AMF applies NAS encryption & integrity (outer header, MAC)
[7] AMF sends to UE via gNB
```

---

### 🧾 Extra Notes

* **QoS Rule** (`qos_rule`): Describes flow filters and associated QoS characteristics.
* **AMBR**: 0x03f424 = 256,000 kbps (262,144 kbps ≈ 256 Mbps).
* **PDU Address**: 10.45.0.2 assigned by SMF as the UE's IP.
* **EPCO**: Optional container for enhanced protocol config (e.g., DNS).
* **DNN**: "internet" in ASCII hex (`0x696e7465726e6574`).
